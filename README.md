# Fit Log

Fit Log is a modern fitness exercise tracking web application built with Next.js. 
It allows users to explore different exercises, view exercise details, add exercises to today's workout plan, and save exercises for later.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- Context API
- REST API

## Key Features

1. Exercise Library
   - Browse a collection of exercises with images, muscle groups, equipment, duration, calories, and ratings.

2. Exercise Details
   - View detailed information about each exercise, including instructions, sets, reps, duration, calories burned, and difficulty.

3. Today's Workout Plan
   - Add exercises to today's workout plan and easily manage the selected exercises.

4. Save for Later
   - Save favorite exercises and access them later from the "My Plan" section.

5. Responsive & Modern UI
   - Fully responsive dark-themed interface designed for a smooth experience across desktop, tablet, and mobile devices.

## Project Overview

Fit Log is designed to make workout planning simple and organized. Users can discover exercises from the library, check their details, add them to their daily workout plan, and save exercises for future workouts.
